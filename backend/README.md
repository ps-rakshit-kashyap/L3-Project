# TalentForge Backend

FastAPI backend for TalentForge AI-powered hiring platform.

## Features
- **Phase 1**: FastAPI architecture, health checks, settings, and lifecycle management.
- **Phase 2**: Supabase PostgreSQL database, SQLAlchemy 2.x ORM, Alembic migrations, and resume storage.
- **Phase 3**: Supabase Auth JWT verification, RBAC permissions (ADMIN, RECRUITER, CANDIDATE), and resource ownership guards.
- **Phase 4**: Resume text extraction (PDF, DOCX, TXT) and AI Resume Screening Agent with structured output.
